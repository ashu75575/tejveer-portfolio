# Tejveer Singh — Portfolio

Personal engineering portfolio of **Tejveer Singh**, Full-Stack Developer & Generative AI Engineer based in New Delhi, India.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Motion & 3D**: GSAP, Framer Motion, OGL
- **Icons**: Tabler Icons

## Featured Projects

- **ClipForge AI**: Automated short-form video generator with transcription, smart reframing, and multi-platform publishing.
- **DataLens**: AI-powered tabular analytics assistant that translates conversational natural language into interactive charts and deep financial insights.
- **ClauseGuard**: Contract review platform with automated risk scoring and plain-English clause breakdown.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
